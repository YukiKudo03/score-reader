# Score Reader — 自動譜めくり

楽器練習の「譜読み」を支援する、スマホ・タブレット向けの譜めくりアプリ(PWA)です。
譜めくりで視線と音楽が途切れることを減らし、一人でも通して読めるようにすることを目指します。

## いまできること

- **楽譜の取り込み**: PDF、または画像(複数選択でファイル名順に1ページずつ)。楽譜は端末内(IndexedDB)だけに保存され、外部には送信しません。
- **半ページめくり**: 下側を弾いている間に、上側だけを先に次ページへ差し替えます。ページ末から次ページ頭へ、視線が途切れずに進めます。
- **自動めくり(テンポ)**: BPM・拍子・ページごとの小節数から所要時間を計算してめくります。開始前に1小節のカウントイン、任意でメトロノーム音。
- **段マーク**: 各ページで段の中央をタップし、段ごとの小節数を登録します。登録すると
  - 分割線が段を横切らない位置(ページ中央に最も近い段間)に置かれ、下側の段に入った時点で上側が差し替わります。
  - いま弾いているはずの段が、ページ左端の印で示されます。
  - 自動めくり中に段をタップすると「いまここ」と位置を合わせ直せます。
- **演奏を聴いて進む(マイク)**: 弾き始めると進み、音が止まると待ちます。止まったと判断したら、最後に鳴った音の1拍後まで巻き戻して次の音を待ちます。音が鳴り続けている間は長い音符として待ちます(最大で1小節ぶん)。音声は端末内で解析するだけで、録音も送信もしません。
- **手を使わない手動めくり**: Bluetooth 譜めくりペダル(矢印キー / PageUp・PageDown を送るもの)やキーボードに対応。画面タップ(右7割=進む、左3割=戻る)でも操作できます。
- 画面の自動消灯防止、オフライン動作、ホーム画面への追加。

### いまの追従でできないこと

PDF・画像には音符の情報がないため、マイクから分かるのは「弾いているか、止まっているか」までです。

- 弾き直しで前の小節に戻ったことは検知できません(段をタップして合わせ直してください)。
- 実際のテンポが設定より速い・遅い場合は、その分だけずれていきます。
- 音の検出は合成音でのみ確認しており、実際のピアノ・実機のマイクでの調整はこれからです。

## これから

- **楽譜認識(OMR)**: 段・小節の自動検出で段マークの手間をなくし、さらに音符を読み取って、音高の照合による本来の位置追従(弾き直しやテンポの揺れへの対応)へ進める。
- カメラによる顔ジェスチャー(うなずき等)でのめくり
- 横向き時の見開き表示、リピート・ダカーポなどの戻りへの対応

## 開発

```sh
npm install
npm run dev      # 開発サーバー
npm test         # めくりロジックの単体テスト
npm run build    # 型チェック + 本番ビルド(dist/)
npm run preview  # ビルド結果の確認
```

マイクや PWA のインストールには HTTPS(または localhost)での配信が必要です。

## 構成

| ファイル | 役割 |
| --- | --- |
| `src/turner.ts` | 表示位置とテンポ進行の純粋ロジック(テスト対象) |
| `src/layout.ts` | 段マークから分割位置・めくり時点・現在段を求めるロジック(テスト対象) |
| `src/follow.ts` | 演奏中/停止の判定(テスト対象) |
| `src/onset.ts` / `src/mic.ts` | マイク入力からの音の立ち上がり検出 |
| `src/source.ts` | PDF / 画像を同じ「ページ」として描画する層 |
| `src/Viewer.tsx` / `src/MarkLayer.tsx` | 譜面表示・めくり操作・段マーク編集・設定 |
| `src/Library.tsx` / `src/store.ts` | 楽譜一覧と端末内保存 |
| `src/metronome.ts` | クリック音 |
