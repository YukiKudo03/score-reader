# Score Reader — 自動譜めくり

楽器練習の「譜読み」を支援する、スマホ・タブレット向けの譜めくりアプリ(PWA)です。
譜めくりで視線と音楽が途切れることを減らし、一人でも通して読めるようにすることを目指します。

## いまできること(第1段階)

- **楽譜の取り込み**: PDF、または画像(複数選択でファイル名順に1ページずつ)。楽譜は端末内(IndexedDB)だけに保存され、外部には送信しません。
- **半ページめくり**: 下半分を弾いている間に、上半分だけを先に次ページへ差し替えます。ページ末から次ページ頭へ、視線が途切れずに進めます。
- **テンポ自動めくり**: BPM・拍子・ページごとの小節数から所要時間を計算して自動でめくります。開始前に1小節のカウントイン、任意でメトロノーム音。
- **手を使わない手動めくり**: Bluetooth 譜めくりペダル(矢印キー / PageUp・PageDown を送るもの)やキーボードに対応。画面タップ(右7割=進む、左3割=戻る)でも操作できます。テンポ進行中にずれたときも、これで位置を合わせ直せます。
- 画面の自動消灯防止、オフライン動作、ホーム画面への追加。

## これから(第2段階以降)

- **演奏音への追従**: マイクでピアノの音を聴き、楽譜上の位置を推定してめくる。
  PDF/画像には音符情報がないため、楽譜認識(OMR)か、小節位置を手動でマークする仕組みが前提になります。
  めくり判断は `src/turner.ts` の表示位置(`Pos`)を進めるだけなので、追従エンジンは同じ口に差し込めます。
- カメラによる顔ジェスチャー(うなずき等)でのめくり
- 横向き時の見開き表示、リピート・ダカーポなどの戻りへの対応

## 開発

```sh
npm install
npm run dev      # 開発サーバー
npm test         # めくりロジックの単体テスト
npm run build    # 型チェック + 本番ビルド(dist/)
npm run preview  # ビルド結果の確認
```

マイクや PWA のインストールには HTTPS(または localhost)での配信が必要です。

## 構成

| ファイル | 役割 |
| --- | --- |
| `src/turner.ts` | 表示位置とテンポ進行の純粋ロジック(テスト対象) |
| `src/source.ts` | PDF / 画像を同じ「ページ」として描画する層 |
| `src/Viewer.tsx` | 譜面表示・めくり操作・設定 |
| `src/Library.tsx` / `src/store.ts` | 楽譜一覧と端末内保存 |
| `src/metronome.ts` | クリック音 |
